# Architecture Decision Records (ADR)

Create an ADR only for durable, significant architectural decisions; trivial implementation details belong in the issue/PR or commit.

Suggested minimal ADR: Context, Decision, Alternatives, Consequences, Status, Date, References.

Example filename: `0001-record-the-first-architectural-decision.md`.

An ADR is a decision record, not a replacement for code, current configuration, or verified runtime status.
